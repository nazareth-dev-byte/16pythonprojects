Quiz App (CLI)

A command-line multiple-choice quiz. You choose a topic and how many questions you want, and an AI model writes the questions. If the AI can't be reached, or returns nothing usable, the app falls back to 5 built-in Python questions.

Features
Questions on any topic, generated by an LLM (Azure-hosted gpt-4.1-mini)
Choose 1 to 10 questions per quiz
Every generated question is checked before use (question text, exactly four options A to D, and a valid answer letter). Bad ones are dropped.
Built-in fallback questions if the AI call fails or nothing valid comes back
Questions are shuffled each game
Immediate feedback after each answer, with the correct answer shown
Wrong-answer messages are picked at random and never repeat back to back
Final score and percentage, with a different message for low, average and high scores
Invalid input shows a message and asks again instead of crashing
Play again without restarting
Requirements
Python 3.12 or newer
Packages: openai and python-dotenv
An Azure AI Foundry model deployment (see setup below)
pip install openai python-dotenv
Setup

Create a file named .env in the top folder of the repository (the folder that contains this project's folder). It needs three values, one per line, with no spaces around the = and no quotation marks:

AZURE_ENDPOINT=<your endpoint>
AZURE_API_KEY=<your key>
AZURE_MODEL=<your deployment name>

Never commit this file. It is listed in .gitignore, so check with git status that .env does not appear before you commit.

How to run

From the project folder:

python quiz.py
How to use
Choose 1 to start a quiz, or 2 to quit.
Enter how many questions you want (1 to 10).
Enter a topic, or press Enter for "Python basics".
Answer each question by typing A, B, C or D.
See your score, then choose whether to play again.

Project files
quiz.py: the quiz itself (menu, asking questions, scoring, validation, fallback questions)
llm_questions.py: connects to the model, asks it for questions as JSON, and parses the reply
Notes
AI-generated questions can contain mistakes, including a wrong "correct" answer. The app warns you before each quiz.
Each quiz makes one call to the model, and calls use credit. The question count is capped at 10 for that reason.
If the .env file is missing or incomplete, the app can't create the model connection, so set it up before running.
